protocol step 2 sequence instead of a session re-deriving it by hand under
time pressure.

`sync(cwd, branch="main")`:
1. Checks out `branch` if `HEAD` is detached.
2. `git fetch --unshallow origin <branch>` if the repo is shallow, else a
   plain `git fetch origin <branch>`.
3. If `git merge-base <branch> origin/<branch>` succeeds, `git merge
   --ff-only origin/<branch>` — nothing discarded, nothing lost.
4. If no merge-base exists even after a full fetch (a genuine rewrite) and
   the working tree is clean, `git reset --hard origin/<branch>` —
   `origin/<branch>` is authoritative, matching the existing documented
   protocol.
5. If no merge-base exists **and** the working tree is dirty, aborts
   without touching anything and reports why — the one case a hand-run
   session under time pressure could get wrong that the documented protocol
   didn't explicitly guard against.

CLI: `python3 tools/git_sync.py [--branch B] [--cwd DIR]`.

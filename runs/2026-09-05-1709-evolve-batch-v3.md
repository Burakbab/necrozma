own backgrounding) was killed externally (exit 143) after roughly 45-50
minutes with zero generations saved — some outer limit on that particular
backgrounding path shorter than a 25-generation run needs, distinct from
the `nohup`-inside-one-tool-call anti-pattern Next-steps item 9 already
warns about (this wasn't that; the harness itself moved the command to a
tracked background task, then killed it). Re-ran as `evolve 10` via a
detached `nohup ... &` this time, polled to completion with `Monitor`

through `tail -60` before being written to its own log file, so generations
1-3's output was permanently lost — the file *is* the record for a
backgrounded command, and truncating it before capture throws away data
that can't be recovered afterward, unlike a `tail` applied only when
*displaying* an already-complete file. Beat-rate for this batch is reported
as "12/12 visible" rather than "15/15", not because 3 generations differed,
but because their output was never captured. Fix for next time: background
the plain `python3 evotrader_bundle.py evolve N` command with no pipe at
all, or pipe to `tee` instead of `tail` if a shorter live view is wanted.

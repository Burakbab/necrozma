recurring shallow-clone/rewrite staleness this file already documents.

Also: `tools/background_runner.py wait` was first invoked with an
unsupported `--pid` flag, which failed argument parsing but still exited
0 (usage text printed, no actual wait performed) — caught by checking
`kill -0 <pid>` directly afterward and finding the evolve process still
running, then re-invoking `wait` with only the supported `--status`/
`--timeout` flags, which blocked correctly until the real process exited.
Worth remembering: `background_runner.py wait`'s exit code does not by
itself confirm it waited — check its stdout for an argument-parsing error,
not just its exit status.

## Process note

Made (and caught) the exact single-vs-double-backgrounding mistake AGENTS.md
item 9 warns about: the baseline post-batch `pytest` run was launched with
both the tool's own `run_in_background: true` AND a trailing shell `&`,
which returned almost instantly while the real process kept running
detached. Caught immediately (the log file was visibly truncated mid-run,
`ps aux` showed the real PID 1076 still alive), recovered by polling that
real PID directly (`while kill -0 1076; do sleep 3; done`) rather than
trusting the tool's premature completion signal. No harm — just re-confirms
the item 9 rule: never mix the tool's own backgrounding with a trailing `&`.
